# i18n (ID/EN toggle) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an ID/EN language toggle next to the theme toggle that instantly translates UI chrome and persists across visits.

**Architecture:** Custom `src/lib/i18n.ts` store (mirrors `src/lib/theme.ts`): localStorage-backed `getUILocale` read on every call plus a `ui-locale-change` window event, so Astro `<script>` bundles and React `client:*` islands (which do not share module state) stay in sync. React islands use `useUILocale()`; Astro-rendered TopBar strings swap via `data-i18n` / `data-i18n-aria` attributes.

**Tech Stack:** Astro 7, React 19 islands, Tailwind v4, TypeScript. No new dependencies.

## Global Constraints

- UI chrome only — skill markdown bodies, starter code, preset/scenario/cheat-sheet/terminal content stays English.
- Proper names stay English in both locales: `Backend Roadmap`, `Git Playground`, `Design Studio`.
- Default locale English; persist under `backend-roadmap:ui-locale`; instant switch, no reload, no routing change.
- Follow existing patterns in `src/lib/theme.ts` (store) and `src/lib/languages.ts` (persisted hook).
